# 短视频 AIGC 工作流

一个面向短视频内容生产的可视化工作流编排平台。通过连接输入、文本处理、代码执行、互联网检索、图片生成、视频生成、循环与时间线合成等节点，可以搭建并运行不同类型的视频生成流程。

## 功能概览

- **可视化工作流编排**：在画布中新增、连接和配置节点，支持复制工作流及自动保存。
- **多模态生成节点**：统一编排文本、图片、音频与视频任务，并在节点间传递结构化结果。
- **上下文与变量引用**：节点可通过 `${变量路径}` 引用流程输入和上游输出，减少重复配置。
- **循环与结果汇总**：可对结构化列表逐项执行子流程，并将结果整理为时间线或其他下游数据。
- **代码执行**：在受限环境中运行可编辑 JavaScript，用于数据转换、校验和上下文合并。
- **Excel 数据读取**：代码节点支持附加 `.xlsx` 文件，并通过内置 API 读取工作表数据。
- **互联网内容检索**：按查询词或指定公开 URL 获取网页正文，供后续节点处理。
- **人物资产管理**：按工作流维护角色描述、参考图和连续性标识，便于跨镜头复用视觉设定。
- **模型配置管理**：集中维护生成服务的连接参数和凭据，并提供测试入口与脱敏诊断信息。
- **执行记录**：查看工作流和单节点任务的状态、耗时、结果与错误信息。
- **持久化存储**：使用 PostgreSQL 保存工作流、服务配置、执行记录和人物资产。

## 通用节点能力

### 代码执行与 Excel

- 代码执行节点提供 JavaScript 编辑器，支持上传单个 `.xlsx` 文件，最大 15MB。
- 运行时可使用 `${变量路径}` 占位符、`context`、上下文顶层变量、`files`、`prompt`、`console` 和同步 `excel.parse(file, options)` API。
- `excel.parse` 返回工作簿、工作表、表头、数据行、原始行号、总数与截断标记；业务匹配和字段转换由节点代码完成。
- 返回对象中的 `contextPatch` 会安全地深合并到流程上下文，其余返回值保存在节点结果中。
- JavaScript 在受限的同步环境中执行，不提供网络、文件系统、动态代码生成或模块加载能力；单次结果上限为 4MB。

### 互联网检索

- 支持按查询词检索，也可以抓取指定的公开网页 URL。
- 仅允许公开的 `http/https` 地址，并拒绝本机、私网地址和非网页协议。
- 请求带有超时、正文大小和结果数量限制，输出包括正文、最终 URL、抓取时间及失败信息。
- 检索结果只进入当前流程上下文，不会自动写入知识库。

### 媒体生成与连续性

- 图片、音频和视频节点采用统一的输入输出方式，可组合为文生图、参考图生成、图生视频等流程。
- 支持在不同镜头间传递参考图、首尾帧、角色资产和提示词，以保持画面连续性。
- 时间线节点可汇总循环生成的媒体结果，形成便于预览或后续渲染的数据清单。

## 数据库配置

开发环境默认使用以下连接：

```bash
DATABASE_URL=postgres://postgres:postgres@localhost:5432/video_aigc
```

如需自定义连接，请复制 `.env.example` 为 `.env.local`，然后修改 `DATABASE_URL`。

应用启动时会自动创建所需数据表，也可以手动初始化：

```bash
createdb video_aigc
psql "$DATABASE_URL" -f database/schema.sql
```

## 本地开发

```bash
npm install
npm run dev
```

也可以通过脚本管理数据库和开发服务：

```bash
./start.sh start
./start.sh restart
./start.sh stop
./start.sh status
```

首次运行且数据库中没有配置时，应用会写入基础配置。后续工作流编辑会自动同步，服务配置则在保存后写入数据库；敏感凭据不会在诊断界面中以明文展示。

## 构建与检查

```bash
npm run lint
npm test
npm run build
```

需要应用已启动的端到端检查：

```bash
npm run test:smoke
```

生产环境所需的生成服务连接信息，请在应用的配置页面中按实际部署环境填写。
