# 创作工作台界面改造

参考 [LibTV](https://www.liblib.tv/) 的公开页面、[颜色定义](https://liblibai-web-static.liblib.cloud/liblibtv_online/static/_next/static/chunks/129_y89ca9lu0.css)与[页面样式](https://liblibai-web-static.liblib.cloud/liblibtv_online/static/_next/static/chunks/2_xx028mz-y3h.css)，在现有 React 工作台上实现。保留原有导航名称、模型接口、工作流、执行记录及人物资料。

## 已实现

- 全站使用炭黑底色与青蓝主按钮：页面 `#141414`、侧栏 `#161616`、面板 `#1a1a1a`、浮层 `#242424`、强调色 `#13d5ff`。文字保持足够对比；运行、成功、错误和断点仍用各自的状态色。
- 桌面固定侧栏与折叠菜单，移动端紧凑顶部导航。新建入口直接进入编排并展开基础信息。
- 工作流首页支持名称/描述搜索、生成能力筛选、网格/列表切换、空结果恢复。卡片缩略图来自已保存的节点与连接；较大工作流明确标注仅展示前 24 个节点，没有虚构成片封面。
- 当前执行入口在移动端和操作受限时仍可返回。编辑或复制工作流前保留本次单步游标，返回时恢复；运行中或保存失败时防止新建/打开其他执行覆盖现场。
- 编排画布、执行控制、节点详情、历史记录、人物/造型/声音面板、模型配置及流水统一深色。配置库诊断折叠到次级区域。
- 中等宽度提前切换基础信息与流水布局；历史记录采用容器内横向滚动。补充可见键盘焦点、悬停反馈和减少动态效果偏好支持。

## 验证证据

- TypeScript + Vite 生产构建通过；现有大型 JavaScript 分块提示仍存在。
- 修改的 TSX 文件通过 ESLint；`git diff --check` 通过。
- 40 项现有回归测试通过，覆盖页面状态、画布选择/缩放、调试选中、条件断点、断点回退和详情展开。
- 8 组实际 React 服务端渲染检查通过：空数据、单工作流、30 节点、操作受限、长中文与特殊字符、零节点、受限时返回执行、保存失败提示。按钮命名、禁用状态、HTML 转义及节点概览范围符合预期。
- 6 份 CSS 解析通过；没有未定义的颜色变量。已静态核对 720/721/760/761/900/901/1240/1241px 的关键断点规则。
- 现有开发服务可返回更新后的组件与样式，HTTP 200。验证未调用模型生成。

## 尚未验收的边界

浏览器 Computer Use 被当前网址访问策略终止，本轮没有继续浏览器操作或使用替代控制方式。因此，以上构建、SSR 和 CSS 检查不能视为真实浏览器截图或点击验收。

后续人工检查可从本地开发服务进入：工作流筛选与网格/列表切换；新建/编辑后返回单步执行；画布拖拽与属性抽屉；人物资料及声音面板；窄屏历史记录和模型流水。执行付费生成并非本次界面验收的必要步骤。
