# 人物声音实施与验证记录

更新：2026-09-12。状态：实施及真实媒体验证进行中，不代表整体验收完成。

## 已落地

- 人物库支持读取当前可灵账户的预置/自定义音色、试听、确认绑定及查询异步任务；支持通过公开参考声音地址创建自定义音色。
- 声音身份按工作流和连续性标识建立稳定逻辑 ID，声音版本独立于三视图更新。
- 新执行采用严格声音策略；旧执行保留原策略并显示音色未锁定。执行快照持久化；重试、恢复沿用同一声音身份。后续场景新增人物只追加新身份，不覆盖已有条目，不改变旧镜头的请求指纹。
- Kling 3 Omni 请求引用已经绑定声音的 element_list。标准 Kling 3 不能使用独立 voice_list，现已在提交前拦截；此前对此路径的实现判断有误，已按真实拒绝及官方能力矩阵修正。独立 voice_list 只编译到 Kling 2.6 首帧图生视频、pro 1080P、5 或 10 秒的路径，该路径旁白样片正在验证。长度或能力限制不会通过静默丢弃声音字段处理。
- 供应商主体及音色任务在提交前持久化本地 ID，保存远端任务 ID；提交状态不确定时按同一任务恢复查询。明确失败释放待处理状态；重复刷新只创建一个版本。
- 成片听审可以记录通过、不一致、证据不足；记录与具体视频及人物声音版本绑定。严格声音片段未通过听审时阻止 timeline.compose；更换视频或声音版本后旧结论失效。
- 人物详情支持查询已锁定的执行版本和视频请求记录，分别显示总数及最近 100 条。以稳定人物 ID 匹配，三视图重画可复用查询，同名不同人物隔离；视频重试按请求条数展示，不冒充镜头总数。该查询不会升级快照或发起媒体请求。
- 已绑定的历史视频支持选择人物，预览声音版本差异与重做节点，创建单独的待执行换声分支。所选人物在该执行中的所有已知视频都会失效，继续沿用现有连续性依赖重做规则；无声音证据的视频保守失效。原执行、原视频和未选人物的快照保留。创建分支不调用模型；恢复与重试使用新分支的声音快照。
- 新界面在严格视频请求前核验 `voiceContractVersion`，未更新的服务会被明确阻止，不能静默跳过音色绑定。
- 人物声音版本支持填写原因后停用与恢复；可用性独立保存，不改写冻结快照。停用阻止新的视频合成，已提交任务恢复查询和旧成功结果读取仍允许，其他人物不受影响。换声预览也拒绝使用已停用的新版本。

## 声音如何生成

当前可灵账户已实际读取到预置音色，因此可以直接试听选用，无需先接独立 TTS。自定义路线是参考声音 → 可灵自定义音色任务 → voice_id → 人物主体绑定 → 分镜原生台词演绎。

参考声音可以来自录音，也可以来自另一个配音模型生成的样音；当前项目只有 Local 静音音频模拟器，尚未配置真实独立配音服务，不能用该模拟器制作正式样音。当前自定义入口接受供应商可访问的 HTTP(S) 素材地址，尚不支持把本机上传文件自动公开托管。

## 官方接口依据

核查日期为本记录日期，兼容项目当前 `/v1` 接口，未混用新版视频请求格式。

- [Voice Management](https://kling.ai/document-api/api/video/3-0-omni/voice-customization)：预置音色查询、自定义声音创建与任务查询；参考为 5–30 秒干净单人声音。
- [Element Management](https://kling.ai/document-api/api/video/3-0-omni/elements)：多图人物主体可以通过 element_voice_id 绑定音色。
- [Image to Video legacy](https://kling.ai/document-api/api/video/3-0-omni/image-to-video/legacy)：该页列出共享 voice_list 字段，但不能据页面分类推定所有版本都支持；具体需按[能力矩阵](https://kling.ai/document-api/guides/capability-map/video)，独立音色控制限 Kling 2.6 的 1080P、5/10 秒图生视频。voice_list 上限两种音色，与 element_list 互斥；不是 Lip-Sync API 的声音 ID。
- [Omni legacy](https://kling.ai/document-api/api/video/3-0-omni/video-omni/legacy)：使用人物主体及图片参考，不向该端点猜测发送 voice_list。

- Kling 3 标准图生视频 + 独立固定音色请求实际返回 HTTP 400/code 1201，消息 `The current model does not support voice control.`，没有返回任务 ID。证据 `video-narrator.json`。不能称其为旁白样片成功或断言已支持。
- 重新查看官方能力矩阵，确认独立 Voice Control 在图生视频中仅列于 Kling 2.6（1080P、5/10 秒）；Kling 3 人物主体路径与其不同。已去掉错误的标准 v3 voice_list 支持，并增加无供应商 POST 的拒绝回归测试。
- 2.6 适配器只接受首帧、pro、5/10 秒、最多两种声音；不接受尾帧。旁白提示明确来自画外，不新增画内人物。运行契约提升到 `character-voice-v2`，旧验证服务需要更新。
- 在不更改已保存模型配置的情况下，用同一账户发起一次 2.6/5 秒/pro 旁白探针，供应商已接受任务 `927499648397893632`；真实生成仍在处理中。持久化文件 `video-narrator-v26.json`，恢复脚本 `run-narrator-v26-acceptance.mjs` 必须优先按已有任务查询，不能重复 POST。

- `preflight-tests.log` 覆盖解析、未知模板排除、历史输入不污染、缺失后镜人物、无对白开场、原执行恢复。
