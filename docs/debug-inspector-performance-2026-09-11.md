## 根因与修改

- 原上下文树即使 `<details>` 关闭仍递归渲染整个子树，包含输入框、媒体和 React 节点。第 3 轮视频节点输入及上下文遍历有 15,368 项、10,948 个叶子值、159 处媒体引用。隐藏并不等于卸载。
- 新增 `InspectorDisclosure`：展开才执行子树渲染函数，收起卸载子树，嵌套 toggle 不影响父级。
- 新增 `InspectorEntries`：对象、数组和日志每页最多 50 条，可翻页访问全部数据；翻页释放旧页。切换执行记录、节点或分支历史时重置局部展开状态。
- 仅顶层直接媒体默认展开，视频与音频不预加载。保留展开、文本编辑、媒体放大和下载入口。
- 历史列表不再积累已打开记录的完整执行结果；执行页不再额外构造编辑器模拟调试快照。
- 不修改执行状态存储格式、历史证据、生成参数或工作流拓扑。
