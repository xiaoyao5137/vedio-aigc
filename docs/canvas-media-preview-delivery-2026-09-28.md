# 工作流画布媒体预览

工作流详情、编辑和执行页面共用节点媒体预览。详情入口在列表卡片封面/名称，编辑仍保留“编辑编排”。

- 图片可放大，视频和 TTS/其他音频可直接播放，数组结果可翻页。
- 显式区分“本次生成”和“引用素材”。执行页面使用所查看轮次/分支的节点快照；编辑页面的引用跟随当前配置，生成结果仍来自所查看记录，并显示记录 ID。
- 支持上传文件、本地媒体、远程/带签名链接、data URL、常见模型包装、逐项生成结果和音色试听地址。最终输出优先于原始供应商中间结果。
- 生成中、失败、跳过、无结果、加载失败分别显示状态；播放器按画布可见区域挂载，不自动播放。
- 预览开关采用显示坐标投影；保存的节点坐标不因开关改变。拖拽反算原坐标，普通连线、分支回跳和循环边界使用同一投影。

## 验证

相关单测 52 项通过，覆盖媒体提取、快照优先级、危险/无效链接过滤、原始记录不修改、可逆坐标投影、选择/缩放和循环/分支检查逻辑；TypeScript 与生产构建通过。本次相关文件及最终全量 ESLint 均通过。

使用独立 Vite 验证服务运行实际 App，API 配置/记录写入只在进程内存，生成接口阻断。媒体是已有 JPEG、12.04 秒 1280×720 视频、11.47 秒 TTS 音频；不是此次新生成。另检查了正式本地服务中的打工猫参考图片。

Chrome 浏览器验证：

1. 详情只读，图片加载并翻页，音频完成解码；缩放 71%→89% 生效，开关隐藏/恢复预览。
2. 编辑图片引用地址后，去重后的引用数立即由 2 变 1。
3. 历史执行第二轮待执行时“本次生成”为 0；切到第一轮后，图片、视频和音频均显示该轮输出。
4. 视频/音频 `readyState=4`，视频实际播放至结尾，音频可播放；视频放大弹窗可打开/关闭。
5. 素材翻页未打开属性抽屉；预览/缩放不改变保存坐标。拖拽 48×36 屏幕像素按画布缩放和投影反算后保存，逆向拖拽恢复原位置。
6. 返回编辑/详情仍显示所选第一轮产物及记录 ID。
