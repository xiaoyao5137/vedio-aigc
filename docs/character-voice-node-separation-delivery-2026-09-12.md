# 人物原创音色：实现与首轮验收

## 已实现的工作流

人物图片准备 → **人物原创音色创建（音频模型）** → **人物音色资产归档（资产节点）** → **人物资产归档** → 首帧参考整理 → **参考生视频**。

- 音色创建使用已配置的百炼 Qwen Audio TTS Plus，依据人物描述调用声音设计接口；不使用预置音色。推理模块不依赖数据库，不包含人物或音色入库操作；本地传输回执用于避免重试重复创建。
- 音色归档独立保存声音身份。人物归档再关联 `metadata.originalVoice`，并准备视频供应商所需的声音映射。
- 人物库按 `workflowId + continuityKey` 召回。已有图片不会阻断声音创建，已有声音不重复创建；执行快照锁定实际声音引用。
- 旁白作为独立声音角色归档，使用 `__narrator__`，不生成旁白人物图片或画内主体。

## 视频如何引用声音

画内对白：把原创 TTS 声音样本转成可灵自定义声音和主体资产，视频请求使用 `element_list` 参数，并通过 Prompt 的 `<<<element_n>>>` 绑定说话人。百炼 voice ID 与可灵 voice/element ID 分开保存，不能互相替代。

画外旁白：把归档的原创 `voice_id` 直接传给 TTS，按已批准的旁白时间窗合成，再与视频的画面和环境音混合。视频供应商的画面请求不包含旁白原文；原分镜、台词和排程保持原样。超出自然语速范围时阻断，禁止截断；成功的付费画面有独立回执，混音失败后复用画面。

接口依据：[百炼声音设计 API](https://help.aliyun.com/zh/model-studio/voice-design-api-references)、[可灵 Omni API](https://kling.ai/document-api/api/video/3-0-omni/video-omni/legacy)。供应商行为同时以保存的真实请求、资产任务和视频结果为证。
