# 张飞人物资产补全与同脸修复验收记录

日期：2026-09-28。适用工作流：`wf-sanguo-history-drama`。本记录补充[人物聚合资产与工作流召回规格](./character-person-assets-spec-20260928.md)。

## 原因与修复

1. **正史栏目空白。** 第 610 集执行已取得《三国志·张飞传》引文，但其人物史料节点受“缺三视图才运行”条件限制；已有三视图时不能补传记。一次补检索还收到 HTTP 429，旧的自动占位传记又被冲突写入规则保留。现将人物史料节点改为每次检查具名人物，优先传入本集已取得的 `historical_sources`；图片生成仍只对缺图人物运行。传记合并按人物、出处及原文片段核对，可在后续执行补齐失败或部分证据，保留人工编辑和显式清空。
2. **声音未显示。** 张飞的 Kling V1 原创音色已在 `original_character_voices` 归档，并非声音模型生成失败。人物聚合接口和列表/详情此前没有把人物级声音关联与预览显示出来；现按人物身份汇总，原有音色、试听文件、三视图 ID 与历史执行不变。
3. **同人物造型换脸。** 保留用户选定的长坂帅气版 `character-mukn7n7k-xzu2tb`。为第 610 集江州造型生成并归档 `character-2adc61b636f93ba0`；以同一张已核验脸部快照做离线同阶段比较，距离 0.495，小于当前分流阈值 0.55。四张差异较大的旧图距离 0.708–0.837，标为 `superseded`，默认召回跳过；四张历史付费 PNG 也已下载至内容寻址本地文件，原远端 URI、内容哈希及迁移前行快照留存，历史资产 ID、提示词及执行快照未改。两次新付费候选原始 PNG 均已保存，未采纳候选不进入当前人物版本。
4. **长期防回归。** 同年龄阶段新图先镜像留存并检查身份一致性；超过阈值或无法检测时保存候选、标为待核验、停止本次下游媒体购买，不自动重复购买。人物库把当前、历史和待核验版本分开；自动召回及人物造型目录跳过后两类。详情可对候选与保留版对照，填写说明后接受或拒绝；决定绑定实际本地图片哈希并保留原始检测分数。原图暂不可读时保留原 URL、指纹、任务 ID 和诊断，可只重抓原图后审核，或明确放弃再显式修订。旧 checkpoint 重放不能清掉淘汰、待核验及人工决定。已审核或已付费三视图换图需另建版本，避免旧像素证据套到新图。

## 现场资产

- 张飞传记的人物级记录已依据同一执行中的《三国志·张飞传》引文补齐“正史生平原文”“正史体貌记载”。正史仅能支持“雄壮威猛”和“瞋目横矛”等体格、事件神态，不能推出确切身高、脸形、肤色和须发；这些仍标作剧作设定。
- 当前可自动召回的张飞三视图为长坂与江州两种成熟阶段造型；另有四张历史候选保留供追溯。人物聚合接口可读到“张飞原创 V1”音色。
- 人物资产已增加一件文字装备“长矛”，无伪造装备图片。史料只写“横矛”；“长矛”是第 518 集已批准场景使用的道具称谓，具体长度与形制属于剧作设计。它可适用于成熟阶段两种造型，但只有分镜明确要求时才绑定，不能因库存存在而自动加进第 610 集。
