## 已实现的行为

| 范围 | 实现及验证入口 |
| --- | --- |
| 统一预算 | `duration-policy.ts` 区分对白、旁白、吟诵、歌唱；启动、停顿和收尾同源。冷启动估计明确为保守基线，不伪称实测分位数。 |
| 完整节拍 | `duration-schedule.ts` 验证主体、群体、依赖、资源冲突、原文锚点、必须完成态和无词声部；按预算上界排程。15 秒放不下则按原节拍拆段，禁止钳短。 |
| 时长选择 | 规划入口按安全上界取整，模型低报时由共享编译器选足片长，保留 modelDuration 与调整原因；已有签名和付费入口严格校验，不能自动掩盖篡改。允许最多一个有依据的保守整数秒，9 秒只是回归样例。 |
| 单一时间轴 | 提示词、对白窗、采样时刻从节拍编译，保存 SHA-256 排程签名。服务器在付费视频提交前重算，拒绝改时长、删词、换演员、改窗口或沿用旧签名。 |
| 音频边界 | ASR 同时保留已匹配区间和原始人声候选区间；句首、句尾或对齐缺失时保留 uncertain，不再用最后一个匹配字证明整句结束。 |
| 收尾验收 | `duration-completion.ts` 逐节拍核验原生帧、声音和材料身份；声音可先结束，动作可随后完成，最终取所有必需部分的最晚完成上界。自然呼吸或背景微动不要求停止。 |
| 失败分支 | 确证未完成回到分镜重排，最多自动重排一次；证据不足补查同一素材，不能走原样付费重拍。无词声部缺可靠音频观察时暂停复核。 |
| 时间窗含义 | 每条义务独立保留 reference/hard 分类与原文；参考窗外发生允许查找同素材实际事件，强制先后和截止不放宽。 |
| 剪辑 | 只有完整且留足可读余量时才可考虑剪空等；剪点保护实际完成上界和共享收尾余量，剪后仍需重新采证。 |
| 可观测 | 执行输出增加预算、请求、实际片长、实际完成区间、与预算差值、逐句音频边界，区分待生成、待审核、已验收。 |
| 校准 | 按素材 SHA-256 去重，按策略、供应商版本、表演类型、单人/群体分组；截断、未知、版本缺失等样本不入成功用时分位数。至少 30 个可靠样本才显示描述性分位数。 |
| 审核输入 | 审核只接收当前编译结果，raw/text 原稿仍留存；明确有词 speech 与无词 vocalization 的区别，保持原动作同时性和原剧情节拍绑定；同时性判断核对实际时间交集，首帧或全程覆盖须有原文依据。 |
| 提交提示预算 | 完整图像准备后的提示计数，系统自动身份姿态和口型约束去重；原分镜正文不截断。真实样例正文 1945 字符，最终请求 2471 字符；2501 字符仍在供应商 POST 前被拒绝。 |
| 空景入画 | 新版已签名排程允许首帧无人：参考资产的入场主体、原路径和起止必须匹配已编译动作，发声不能早于入场结束；旧版行为不变。付费前真实预检发现旧规则后修复，10 项相关回归通过。 |
| 历史隔离 | 读取、恢复、手动重试均阻止把旧排程混入新门禁；专用脚本只插入新记录并从首分镜重排，原记录不更新。 |

新的模型分镜已通过内容审核，单次实片验证保存原始响应、实际解码时长、采证及 ASR。视频生成、格式正确或 ASR 通过均不等同于“所有动作已经完成”。无词群众哼唱的可听性和曲调要求必须有真实音频观察；没有音频证据时门禁会暂停，而不会把画面姿态解释为声音已完成。
