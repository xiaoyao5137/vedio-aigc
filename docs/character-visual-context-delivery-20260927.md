本次人物方向按用户确认：脸好看、肤色偏白，保留成熟、壮实、威武的武将气质；长坂张飞使用黑发黑须，不作白发白须的老年形象。这是艺术外貌设计，不能宣称复原了历史肖像。《三国志·张飞传》未提供确切生年，不能由民间生年或小说年龄推算他的长坂实岁。[原典](https://zh.wikisource.org/zh-hans/關張馬黃趙傳)

## 已实现的通用链路

- 大纲按本集史事时间为每个人物设计年龄阶段、年龄依据、剧情时间、稳定服装场合与须发/体型要求。确证或估计年龄须引用本集已核对史料；未知则使用 unknown 或明确的艺术年龄设定。
- 大纲接收有上限的相关人物已有造型目录，复用固定定义，避免同一服装因文字改写反复建图。
- 分镜继承批准的场景版本；分镜前外观查询和之后人物召回都使用本场年龄/场景条件。同场连续镜头不得偷偷换年龄和固定服装。
- 人物库按人物、年龄、稳定场合匹配，不把地名、每镜动作、情绪当新资产；同一造型 key 改写服装定义时先报冲突，不自动购买新图。
- 新版本保留同人物已核对脸部参考；声音身份独立于视觉年龄/造型，优先继承同人物既有身份，多义身份拒绝随机选择。
- 三视图保留横向单行正面/侧面/背面、中性全身站姿和纯背景。工作流归档时将生成请求、图片 URL 指纹与实际观察证据分开保存，未知观察不能给旧图补盖明确年龄。
- 同人物脸部参考从与原图指纹绑定的本地核验快照提取：离线检测正面板眉眼鼻关键点，裁除头发、嘴部、胡须和服装，并灰度化隔离旧肤色，再经图片适配器转换为 base64。新年龄/造型只引用此局部身份图，严格审核的拒绝重试也不退回被拒整图；输出仍要求彩色并服从当前肤色设计。原图 URI、人物 ID、源图/裁片指纹和裁剪依据保留。检测不可靠时在付费提交前失败，不退回整张旧图。当前本机使用 macOS Vision；其他平台若无有效缓存，则明确报告能力缺口。
- 外观审核读取实际配置的视觉模型；配置错误明确失败。新界面校验服务端年龄契约版本，防止旧服务按名字返回其他年龄的图。
- 人物库增加年龄阶段、依据、年代及场合筛选和详情，展示同人物其他版本；派生新版本锁定人物/工作流身份，旧图作为参考，新图字段空白。
- 详情默认展示已存声音摘要，用户点击“配置人物声音”才载入配置面板，避免仅查看资产就创建声音身份。
