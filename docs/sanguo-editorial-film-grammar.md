# 三国工作流影视化开场与承接契约

状态：已实现，待真实新执行成片验收

更新：2026-09-13

## 问题与证据

2026-09-12 最近十条已生成首分镜的执行记录中，首镜虽有“灾年饥民”“郭泰求见”等信息，但仍是人物正戏的第一小段，不是独立的本集开场。跨完整戏的输入统一派生为 `scene_cut`，分镜连续性契约再将其锁定为 `bridgeType=cut`，因此整集观感是人物剧情直接进入、场景之间连续硬切。旧提示还禁止空 `cast`、动画和可读地图，结构上无法表达地图或历史蒙太奇插入镜头。

## 目标与边界

- 让首次观看者在进入人物正戏前知道本集时间、地点/势力、当前危机和核心问题。
- 在显著的地点、时间或势力视角变化处加入有信息职责的承接镜头。
- 继续使用现有“本集场景大纲 → 逐场景循环 → 场景短分镜 → 视频”节点，不新增三国专用节点。
- 不用背景说明替代人物冲突，不机械地在每场之间插地图，不依赖视频模型生成准确可读文字。

## 用户

首次观看某一集、不了解前情与东汉地理关系的普通观众；同时服务于需要可执行镜头清单的编剧、分镜导演和工作流运营者。

## 非目标

- 不把每个场景都改造成纪录片解说或地图动画。
- 不在本次实现确定性文字叠加、片头品牌包装或整集配乐设计。
- 不改写历史记录、已生成媒体或已完成执行前缀。

## 需求

- FR-001 — 新大纲的 `scenes[0]` 必须为 `editorialRole=episode_opening`，首个完整戏必须为 `function=setup`。
- FR-002 — 开场必须通过 `contextPayload` 给出时间地点、历史背景、地理重点和完整旁白，目标时长 4–8 秒。
- FR-003 — 三场及以上的剧集必须至少包含一个 `editorialRole=context_bridge` 的承接镜头。
- FR-004 — `animated_map` 与 `historical_montage` 只允许用于开场、承接或动画化结尾回应；这类镜头可使用空人物数组并跳过人物资产生成。
- FR-005 — 人物正戏保持 `live_action`，每段仍须有 1–2 位具名行动人物、史料锁、节拍覆盖、时长和连续性校验。
- FR-006 — 分镜必须逐字继承 `editorialRole` 与 `visualTreatment`；无人编辑镜头使用“观众”视角，不能凭空加入角色。
- FR-007 — 视频请求按三种视觉处理分别投射真人实景、写实动画地图或统一史料蒙太奇；地图中的地名年代由旁白准确说出，区域高亮承担视觉定位。
- NFR-001 — 迁移不得改变模型选择、重试预算、duration-v2 排程、节点数或连线。
- OBS-001 — 执行记录应保留场景的 `editorialRole`、`visualTreatment`、`contextPayload` 和生成后的实际声画证据。

## 验收

- AC-001 — 给定缺少独立开场、开场超过 8 秒或缺少语境字段的大纲，运行结构校验时必须在付费视频前失败并返回字段级错误。（FR-001、FR-002）
- AC-002 — 给定三个及以上完整戏且没有承接镜头的大纲，运行结构校验时必须失败。（FR-003）
- AC-003 — 给定空 `cast` 的动画地图和人物实景，前者必须通过人物容量检查，后者必须失败。（FR-004、FR-005）
- AC-004 — 给定改写视觉职责的分镜，运行分镜校验时必须失败；合法视频请求必须携带实际视觉处理方式。（FR-006、FR-007）
- AC-005 — 给定 schema 117–119 工作流，迁移后必须为 120，节点数、连线和模型不变，再次迁移必须返回同一对象。（NFR-001）
- AC-006 — 给定 schema 120 的新真实执行，首镜实际视频必须可见地图/历史语境且旁白可听，人物正戏从第二镜后进入；整集中至少一个承接镜头必须实际解释时空或势力变化。代码与文本回放不能替代此项。（FR-001、FR-003、OBS-001）

## 风险

- 地图动画生成质量可能波动；以区域高亮和可听旁白作为当前可验证下限。
- 强制承接镜头可能拖慢短集；因此只在三个及以上完整戏时设最低一个，更多位置由大纲导演判断。
- 空人物镜头会经过原本以人物为中心的媒体审核；需用真实新执行验证媒体门禁没有错误要求人物出现。

## 开放问题

- 是否增加确定性的州郡文字叠加，由产品和后期制作决定；若要求绝对准确的屏幕文字，需要独立的后期渲染能力。
- 一集允许的背景说明总时长尚未设全局上限；先用单镜 4–8 秒和真实观看验收收集样本。

## 发布与回滚

先迁移生产工作流到 schema 120，再从新执行记录验证大纲、首分镜和视频。历史执行记录不改写。若新合同导致不可收敛，应回滚工作流配置备份，不删除已有记录或媒体；已付费生成的前缀继续保留。

## 当前未关闭边界

生成式视频中的精确汉字标签不可靠，因此本版用区域高亮加旁白完成地理识别；若要像纪录片一样显示绝对准确的州郡文字，应在后续加入确定性的后期字幕/图形叠加能力。整集真实成片验收需由 schema 120 的新执行完成。
