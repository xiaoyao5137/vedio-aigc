# Codex 文本与图片审核模型

在模型管理中新增文本模型，供应商选择 `Codex`，填写本机 CLI 的可执行文件路径和 Model ID。服务进程使用本机已有的 Codex 登录状态；每次调用均创建临时工作目录，不修改用户的 Codex 配置。

## 配置

| 字段 | 作用 |
| --- | --- |
| `executablePath` | 可执行文件路径；未填时使用 `VIDEO_AIGC_CODEX_CLI`，再回退为 `codex` |
| `model` | CLI 的 `-m` 模型名 |
| `reasoningEffort` | 显式推理强度；须由所选模型支持 |
| `timeoutMs` | 单次调用时限，默认 180000，最大 3600000 毫秒 |
| `outputSchema` | 可选的 JSON Schema 对象或 JSON 文本 |
| `maxStdoutBytes` / `maxStderrBytes` | 可降低输出上限，最大分别为 8 MiB / 512 KiB |

节点参数可覆盖上述选项。`temperature` 和 `maxTokens` 没有映射到未经验证的 CLI 控制项；切换已有审核节点时应移除这两个旧参数。请求指纹包含供应商、实际可执行路径、模型、推理配置和输出约束，避免复用其他配置的文本缓存。

## 图片与结果

文本节点和模型体验均接受 `reviewImages` 本地 JPEG 地址数组，以及已有的 `reviewImageDetail` 局部裁剪配置。接口先加载固定图片快照，再对同一批字节计算指纹并作为附件提交。原图顺序、局部图来源、帧号、像素区域和 SHA-256 都进入调用记录。局部图不能替代原帧，也不是新的采样时刻。

适配器只执行一次 CLI 调用，输出通过现有文本节点的 JSON 解析及下游业务验收。供应商响应格式本身不会被当作业务 JSON。CLI 返回成功只代表模型调用完成，工作流是否通过仍由验收节点决定。

每次调用启用临时会话、只读沙箱、禁止审批、忽略用户配置和规则，并关闭工具相关功能。JSONL 中若出现工具、未知事件、失败事件，或调用超时、退出失败、正文为空，接口明确失败并保留脱敏诊断。仅允许现场核实过且最终恢复成功的传输重连诊断。隔离证据由按次配置和实际事件共同提供，不等同于 API 的 `tool_choice=none`。

原始文本、事件、实际应用配置、图片哈希及耗时保存在模型调用账本。传输可能先尝试 WebSocket 再回退 HTTPS；当前适配器使用内置 OpenAI 供应商，没有覆盖用户认证端点或强行设置未经核实的传输开关。
