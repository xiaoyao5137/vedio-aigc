## 画面与声音结果

人物、主要服饰、木门背景及站立状态在已查看画面中一致，没有报告确证人物替换、错误手持物或额外人物。三句语音的实际句长均在允许预算内；第二、三句仍有相对计划的时间偏移，原始 `speechValidation.passed=false` 保留。约 0.14 秒尾部余量在当前规则允许范围内，没有因此要求裁尾。

关键未决项是原要求的 **12.47–12.97 秒微微点头**。该窗三张静帧不足以证明完整动作，也不能据此证明动作缺失。尾帧能确认平静站立，但不能单独证明此前点头过程。因此综合报告为 `passed=false / decision=uncertain`，`issues=[]`、`defectEvidence=[]`。

鞋履和内层下裳在开场画外：逐项审核将其列为有依据的非阻断提醒，综合审核仍把重要性保留为未定。这是两份报告的重要性判断差异，不能说鞋履或服饰已经合格，也不是确证服饰缺陷。两份原报告均保留。

逐音素声画同步 **没有得到验证**。静帧嘴形、ASR 时间及语速预算不能证明口型同步通过。画面中后段闭嘴与 ASR 标注终点的差异也不能单独证明真实音画错误。

验收节点返回 `routeError` 和 `samplingRetryPlan`，建议对同一视频增加 12.595、12.845 秒两个采样点，共 15 帧。其 `success` 仅表示节点执行成功；没有 `passed` 字段，没有放行视频。此次进入证据不足分支后，后续叙事/节奏等全部门禁没有继续执行。额外本地契约诊断通过了原要求绑定与缺陷证据检查，但不替代实际画面判断或后续门禁。

为核对漏采风险，另行检查了尾部 45 张原生连续帧（解码编号 292–336，24 fps），覆盖 12.2 秒至片尾的实际显示区间。观察到小幅头部变化，仍不能确信完整点头。该审计独立存档，没有覆写工作流证据或把未知改成已完成。

## 新模型的实际效果

成功重跑采用完整 JSON 响应、映射并发 1：13/13 次模型调用完成；14 次传输尝试中 13 次成功，首帧一次 HTTP 503 过载后重试成功。返回的输入/输出用量共 30,842 tokens；失败传输未返回用量，不能据此推导完整账单。单次调用中位耗时约 36.65 秒。

逐帧对照原图后，13 帧的人物数量、主要外观与场景描述基本吻合；未发现凭空命名人物、编造手持道具或把门缝归给手部的情况。但首帧明确写了“各手指可见、可确认空手”，实际手指被画面下缘裁切，这是一次过度断言。另有少量“可见空手”的范围措辞需要谨慎解释，不能全部计为幻觉。

Astra 的综合审核独立读取原图，13 帧完整持物状态都保留 `unknown`，没有沿用 Sol 的空手断言。这支持保留独立观察与独立审核，不把观察草稿直接当作事实。本样本没有相同条件的旧模型完整对照，不能报告准确率提升或宣称 Sol 普遍更稳定。

## 本次修复与验证

最初流式并发观察出现 `ANTHROPIC_STREAM_INCOMPLETE`，两次模型请求用尽重试；另一次完整响应探针直接返回上游 HTTP 503 过载。保留流式完整结束校验，没有接受半截响应。

通用改动包括：模型设置和单次调用可显式选择流式/完整响应；实际返回方式写入传输元数据并参与请求指纹；设置与模型体验界面支持该参数。缺省流式行为保留，完整响应仍检查非空文本、合法结构和截断。Sol 当前设置 `stream=false`，独立观察并发为 1。两个因素同时改变，本次成功不能单独归因于关闭流式。

新增通用执行检查点分叉脚本：先预览、校验源记录哈希，仅插入新记录，保留完成前缀和已生成视频，避免改写原记录。原 `record-2yqxmc` 与基线 `record-dkozzh` 的内容哈希复核未变。节点 34 及以后保持 idle，本轮没有新增视频生成调用。

767 项测试：766 通过、1 项可选 PostgreSQL 测试跳过、0 失败；构建、Lint 和 diff 检查通过。
